小梦织卷 · 便携版说明
======================

1. 双击 xiaomeng-zhijuan.exe 直接运行（无需安装）。
2. Windows 10 需要已安装 WebView2 运行时（Win11 自带）；
   若无法打开，请先安装：https://developer.microsoft.com/microsoft-edge/webview2
3. 模型接入（任选其一）：
   · 本地 llama.cpp / Ollama / LM Studio（OpenAI 兼容端口）
   · 设置页 → 模型服务 → Base URL 填入后「自动探测」或「测试连接」
4. 故事数据保存在本机：%APPDATA%\com.xiaomeng.zhijuan\
   （便携数据与安装版不互通；如需迁移，使用应用内导出 JSON）

提示：AI 续写需要接入模型服务后才能使用；
未接入时可体验完整界面与交互流程。
