# 验收演示脚本（纯 Mock，无网络）

前置：设置 → 模型名填 `mock`（或清空模型名），无需任何网络与本地模型。

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 启动应用 | 自动进入编辑器，顶部显示「未命名故事」 |
| 2 | 在输入区输入故事开头，按 Ctrl+Enter | 右栏骨架屏 + "小梦正在做梦…"呼吸动画 |
| 3 | 稍候 | 三张候选卡片出现；第一条自动以红色填入正文并带下划线游标；工具条（撤回/修改/继续）悬浮 |
| 4 | 点击右栏第二张卡片 | 正文红色段落替换为第二候选；选中态切换 |
| 5 | 点「继续」 | 红色转深灰，自动发起下一轮；新红色段落出现 |
| 6 | 再点「继续」 | 第三段生成 |
| 7 | 按 Ctrl+Z | 撤回一段（红色消失，树指针回移） |
| 8 | 九宫格 → 平行世界树 | 纵向时间线展示全部节点与分叉标记 |
| 9 | 点击首个节点 | 穿越：正文只剩开头；指针移动 |
| 10 | 输入区写一段新走向，Ctrl+Enter | 长出新分支 |
| 11 | 九宫格 → 导出 TXT | 保存当前时间线正文 |
| 12 | 九宫格 → 导出 JSON | 保存完整故事树（含全部候选与分支） |

通过标准：全程无系统级报错框；所有错误以界面内卡片呈现。
