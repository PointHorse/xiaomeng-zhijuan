# 设计令牌（Design Tokens）

代码化定义见 `src/styles/tokens.css`，本文件为设计基准文档。

## 色板

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--accent` | `#F0655A` | `#FF7A6E` | 主红：候选卡片选中描边、生成正文、游标工具条、换一批按钮 |
| `--accent-hover` | `#E0554A` | `#FF8D83` | 主红 hover 加深 |
| `--accent-soft` | `#FEF0EF` | `rgba(255,122,110,.12)` | 选中卡片底色、hover 浅红 |
| `--accent-text` | `#E04B40` | `#FF9D94` | 红色文字（对比度增强） |
| `--text` | `#303133` | `#E6E6E6` | 正文深灰近黑 |
| `--sub` | `#909399` | `#9A9A9A` | 元信息、副文案浅灰 |
| `--bg` | `#FFFFFF` | `#1E1F22` | 页面背景 |
| `--card` | `#FFFFFF` | `#2B2D31` | 卡片背景 |
| `--border` | `#EAEAEA` | `#3A3D42` | 分隔线、卡片描边 |
| `--menu` | `#9CA3AF` | `#7A7D83` | 九宫格菜单图标 |
| `--cursor-line` | `#F0655A` | `#F0655A` | 生成游标横线 |
| `--skeleton` | `#F2F3F5` | `#33363B` | 骨架屏 |

## 排版

| 令牌 | 值 | 用途 |
|---|---|---|
| `--editor-font-size` | 18px（可调 14–26） | 正文 |
| `--editor-line-height` | 1.9（可调 1.5–2.4） | 正文 |
| `--editor-font-family` | Microsoft YaHei / PingFang SC / 衬线 | 正文 |
| 标题 | 17px / 500 | 顶部栏故事标题 |
| 候选标题 | 22px / 600 | 「没有满意的？」 |
| 元信息 | 12–13px / 400 | 字数统计、保存时间 |

## 形状与动效

| 令牌 | 值 |
|---|---|
| 卡片圆角 | 8px |
| 候选按钮 | 全弧胶囊（999px） |
| 游标工具条 | 右端全弧、左端直角（弧形切角观感） |
| 呼吸动画 | 1.6–1.8s ease-in-out infinite |
| 流式光标 | 0.9s steps 闪烁 |
