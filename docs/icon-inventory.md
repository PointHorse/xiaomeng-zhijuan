# 图标资产清单（阶段 3.5 §5）

> 组件：`src/components/Icon.tsx` — `<Icon name="…" size={n} />`
> 资产目录：`src/assets/icons/<name>.svg`（优先）或 `<name>.png`
> 机制：Vite `import.meta.glob` 预载；SVG 注入时强制 `currentColor`（跟随明暗主题）；
> PNG 以 `<img>` 渲染。**放入同名文件后重新构建即生效，无需改代码。**

当前占位图标来源：Lucide v1.48.0（ISC 许可，可商用/可替换）。

## 绘制规范（供自绘图标统一）

- **画布**：统一 24×24 viewBox，内容绘制区留 2px 安全边距（实际 20×20）。
- **线宽**：统一 2px（与 Lucide 一致），圆头圆角（`stroke-linecap/linejoin: round`）。
- **颜色**：一律 `currentColor`，不写死色值——明暗主题自动跟随文字色。
- **形状语言**：几何简洁、扁平线性；实心仅用于「当前/选中」强调（如圆点）。
- **导出**：SVG 直出；如需 PNG，@2x = 显示尺寸×2、@3x = ×3（如 16px 显示 → 32/48px）。
- **命名**：小写 kebab-case，文件名 = `<Icon name>`。
- **替换流程**：把自绘 `xxx.svg` 放入 `src/assets/icons/` 覆盖同名文件 → `npm run build`。

## 尚用文字/符号的位置（不在图标系统内）

- AI 球「◎ 回到当前」（世界树浮动钮）：字符 ◎，可换 `crosshair` 图标（已备）。
- 编辑页红段工具条文字按钮（撤回/修改/继续）已用图标+文字组合。
- 候选抽屉页码圆点：CSS 圆点，非图标。
